# 🍮 Sonho de Pudim — Confeitaria Artesanal

Site institucional e vitrine digital da confeitaria artesanal **Sonho de Pudim** (Horizonte - CE), desenvolvido para apresentar os produtos da marca e facilitar pedidos pelo **iFood**, encomendas para **eventos**, parcerias de **revenda** e atendimento direto via **WhatsApp**.

🔗 **Acesse o site online:** [https://sonho-de-pudim-hazel.vercel.app](https://sonho-de-pudim-hazel.vercel.app)

---

## ✨ Funcionalidades

- **Vitrine de Tamanhos e Versões:** Apresentação dos pudins nos tamanhos **Individual (120 ml)** e **Família (500 ml — até 8 fatias)**, disponíveis nas versões **Tradicional** e **Zero Lactose**.
- **Modal Inteligente de Atendimento:** Centraliza os canais de contato em um único fluxo:
  - 🛵 **Pedir pelo iFood:** Redirecionamento direto para a loja oficial no iFood.
  - 🎂 **Orçamento para Eventos:** Formulário rápido (nome, tipo de evento, data, nº de pessoas e local) que gera a mensagem pronta para o WhatsApp.
  - 🏪 **Parceria e Revenda:** Formulário dedicado para estabelecimentos parceiros com envio direto para o WhatsApp.
  - 💬 **Atendimento Direto:** Conversa imediata com a confeitaria pelo WhatsApp.
- **Prova Social e Essência da Marca:** Seções com avaliações de clientes, diferenciais artesanais e história da marca.
- **Animações e Responsividade:** Layout 100% responsivo com microinterações, efeito parallax sutil e animações de rolagem via `IntersectionObserver`.

## 🚀 Como executar localmente

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm start
   ```
3. Acesse no navegador:
   ```
   http://localhost:4200
   ```

---

## 📦 Build de Produção

```bash
npm run build
```

Os arquivos otimizados serão gerados no diretório `dist/client`.
